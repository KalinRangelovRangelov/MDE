Markdown Editor — Implementation Plan

Cross-platform desktop markdown viewer & editor · Drafted 2026-05-19

Context

The user wants a cross-platform desktop application to view and edit Markdown. Core needs: a browsable "library" of all Markdown constructs that can be inserted into the text with one action; side-by-side source and preview with the ability to show either one alone or both; and standard file operations (new, open, save, save as) across multiple open documents. It must run on macOS, Windows, and Linux, distributed as packaged installers.

Outcome: a lightweight, fast native-feeling editor that makes GitHub-Flavored Markdown easy to write through discoverable formatting tools and a faithful live preview.

Confirmed Decisions

Stack: Tauri 2 (Rust) + TypeScript/Vite Editor: CodeMirror 6 Render: markdown-it + GFM + highlight.js + DOMPurify Tag library: toolbar + sidebar palette Views: Split / Source / Preview toggle Flavor: GitHub Flavored Markdown Files: multi-tab Distribution: installers (.dmg/.msi/.AppImage)

Components

  • Tab manager — multiple documents; each tab: file path, buffer, dirty flag, cursor/scroll state; close prompts on unsaved changes.
  • Editor pane — CodeMirror 6 per active tab; debounced change events drive the preview.
  • Preview pane — markdown-it render; scroll-synced with the editor in split mode.
  • Tag library — toolbar (bold, italic, headings, link, code, list, quote…) + categorized sidebar palette covering every GFM construct (tables, task lists, fenced code, images, links, HR…). Both wrap the selection or insert at the cursor.
  • View controller — Split (default, synced) / Source-only / Preview-only.
  • File service (Rust) — New, Open, Save, Save As via native dialogs; UTF-8 read/write; returns filename for the tab title.

Data flow

Keystroke → CodeMirror state → debounced (~150 ms) → markdown-it render → DOMPurify → preview DOM. Save → IPC save_file(path, content) → Rust writes → dirty flag cleared.

Error handling

  • File read/write errors surface as non-blocking toast notifications.
  • Unsaved-changes guard on tab close and app quit.
  • Preview sandboxed + sanitized — no script execution, no remote-content surprises.

Testing

  • Unit: snippet-insertion (cursor/selection wrapping), markdown render per GFM construct, tab/dirty-state reducer.
  • Rust: file read/write round-trip.
  • Manual E2E: open → edit → toggle views → insert from palette → multi-tab → save/save-as → unsaved guard, per OS.
  • Packaging: tauri build produces installers on each platform.

Out of Scope (YAGNI)

HTML/PDF export, plugins, math/Mermaid, cloud sync, themes beyond basic light/dark.

Progress will be tracked live in progress.html (same directory), updated frequently during implementation.
